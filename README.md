# FastCat Support

独立实现的客服工作空间。当前版本 0.20.0 提供用户端消息提示音、表情、多行输入、个人头像及优化后的聊天和接入配置界面；包含 Skills、设备绑定、Markdown/结构化消息及分区设置和消息通知；提供本地对话/embedding 模型目录、持久向量索引、语义与 RRF 混合检索及后台检索调试；保留多平台 AI 策略、智能体授权工具、Flutter 悬浮入口、团队管理与工作时间、附件、知识导入、工作流和 AI 草稿。

知识库默认使用 BM25。管理员可配置兼容 OpenAI Embeddings 的模型并建立索引，选择语义或混合模式；自动补索引和额外调用模型的查询扩展默认关闭。索引基于 SQLite 与线性余弦计算，有明确规模限制；真实供应商召回质量仍需联调。见 [逐项结果与限制](./docs/REFERENCE-AUDIT.md)。不开发工具、模型或智能体商店。

当前未达到参考产品全量功能或 UI 一致。逐项状态见 [验收与差异报告](docs/ACCEPTANCE.md)。

## 启动

需要 Node.js 24 或更高版本。

```sh
npm ci
npm start
```

打开 http://127.0.0.1:4310 ，空数据库首次访问会显示管理员设置页面，由部署者填写姓名、登录邮箱、密码并确认；不预置账号密码。设置完成后关闭管理员创建入口，后续访问进入登录页和会话收件箱。升级部署保留已有管理员及数据。访客端为 http://127.0.0.1:4310/widget 。数据保存至 `data/support.db`。

```sh
npm test
npm run format:check
```

测试使用临时数据库和 14310、14311、14320、14321、14330、14340、14341、14360、14361 端口，不改动正式数据库。

## 后台协作与管理

- 管理员生成七天邀请链接，自行分享给同事，不自动发邮件。可管理成员角色与启用状态，最后一位启用管理员受到保护。
- 管理员可管理整个工作空间；客服只处理本人及未分配会话，读取共享知识和快捷回复。客服不能管理成员、模型、渠道、工具或工作流配置。
- 会话转交后，原客服不再访问该会话。停用成员会撤销登录，并将未结束会话退回待分配队列。
- 快捷回复支持分类、搜索、复制及姓名变量 `{{visitor.name}}`、`{{agent.name}}`，插入后由客服核对发送。
- 工作台支持主题、优先级、标签、客服、状态、仅未读筛选，以及每页 40 条分页和批量处理。筛选按账号保存，不保存搜索内容。
- 主题、状态、备注、标签等修改带版本检查；发生冲突需重新打开最新记录，不会静默覆盖其他坐席的修改。
- 客服首次公开回复会认领未分配会话。新消息记录作者，请求标识用于重试去重；旧消息作者不做猜测。
- 全局搜索按访客、主题或历史消息定位会话；访客管理支持资料搜索与会话历史跳转。
- 导出当前筛选的 CSV，最多 10,000 条，超出时提示截取。基础操作记录显示最近 100 条部分管理动作。
- `Ctrl/Cmd + K` 打开搜索，`Ctrl/Cmd + Enter` 发送回复。

目前仍为单组织内的两类角色，没有多租户、团队技能组或自定义资源权限。

## 知识库

在知识库页面创建集合并导入文本、TXT/Markdown、结构化问答或网站正文。内容自动切为 700 字符分块、100 字符重叠，按 BM25 排序检索。支持手动同步网站来源；最多 200,000 字符。另支持 PDF/DOCX 文件（8 MB，PDF 最多 100 页），无向量语义检索或 OCR。网站来源现可按链接进行有限静态采集。

智能体可以绑定特定集合；工作流知识节点可以选择集合。有关联内容或智能体的集合不能删除。

## 工作流

在工作流页面创建流程，用节点配置表单和连接表单编辑画布。支持开始、文本、知识、条件、模型、工具、输出节点。

- `{{input}}`：流程输入。
- `{{nodes.search}}`：节点 `search` 的输出，完整变量保持 JSON 类型。
- 条件节点必须连接 `true` 和 `false` 两个分支。
- 不允许循环、断开的节点或重复 ID。
- 运行记录持久保存；发生错误可查看失败节点及耗时。

当前在服务进程中按拓扑顺序执行，不含后台队列。最多 50 节点、4 个并发流程，同一流程一次运行。重启中的任务记为中断，不自动恢复。

## 工具集成

添加 MCP Streamable HTTP 地址或 OpenAPI 3.x JSON/YAML 文档，点击“连接并发现工具”，选择工具后填写生成的参数表单并执行。工作流工具节点使用保存的工具服务 ID、工具名称和参数。

远程调用、网站导入只访问服务器明确允许的 origin；不会自动跟随重定向。以 `.env.example` 为配置参考，设置环境变量后重启服务：

```sh
INTEGRATION_ALLOWED_ORIGINS=https://tools.example,https://api.example,https://help.example npm start
```

工具需要 Bearer 令牌时，在服务器设置 `FC_SECRET_` 前缀的环境变量，并在工具配置中填写变量名。密钥不存进资源数据或发给浏览器。

协议限制详见差异报告；当前没有 stdio、OAuth 或工具商店。OpenAPI 支持 JSON/YAML 与文档内非循环引用。

## AI 草稿

```sh
AI_BASE_URL=https://your-provider.example/v1 AI_MODEL=your-model AI_API_KEY=your-key npm start
```

在智能体页面点击“调试”，或在会话点击“AI 草稿”。模型读取角色指令、明确的知识范围及可配置历史轮数；旧角色继续保留原历史读取方式。草稿由客服核对后发送；管理员在接入平台中显式启用 AI 策略后，可由选定智能体回复。

也可以在「模型管理」添加供应商，选择 Chat Completions 或 Anthropic Messages，配置基础地址、模型、密钥、默认连接。智能体可选择不同供应商并覆盖模型标识，工作流和平台 AI 回复沿用同一模型路由。

- 密钥使用 AES-256-GCM 加密保存，不通过列表 API 回显。可以替换或清除密钥，也可引用 `FC_SECRET_` 环境变量，环境变量优先。
- 主密钥默认首次保存密钥时生成到 `<DB_PATH>.key`（默认 `data/support.db.key`），权限 0600。可用 `FC_MASTER_KEY` 提供 32 字节 Base64 主密钥。主密钥必须保持稳定；更换后须重新录入供应商密钥，当前不支持批量主密钥重加密。
- 备份需保留数据库及对应主密钥；环境变量主密钥独立保管。缺少正确主密钥将无法解密供应商凭据。源码、日志和用量导出不包含明文密钥。
- 调用记录保留状态、输入/输出及缓存 token、场景与时间，支持日期查询和 CSV 导出。价格配置、费用核算及费用导出已移除；旧数据库历史字段仅作兼容保留，不对 API 暴露。
- 当前 Anthropic 实现文本 Messages 与工具调用，不包含视觉、thinking、Bedrock 或 Vertex 协议。真实供应商凭据尚未提供，当前联调使用本地模拟服务。

## 多智能体协作

编辑主智能体，启用协作并选择 2–4 位独立成员、1–3 轮讨论。成员使用各自指令、知识库和供应商，逐轮读取已有意见；主智能体最后汇总。仅汇总答复进入访客会话，内部讨论记录仅管理员可查看。调试草稿、平台 AI 回复、工作流模型节点都支持协作。

每次最多 12 次成员调用加 1 次汇总，整体 180 秒上限。成员失败会终止整次协作；取消或人工接管会停止后续调用。已完成的调用仍保留用量。当前是固定轮次顺序讨论，没有自动选择成员、嵌套团队或分布式执行。

## 离线队列与消息回执

- 客服与访客的文字、附件先写入本浏览器 IndexedDB，再提交。每个身份最多 100 条 / 32 MB 待发附件；单附件仍限 8 MB。刷新保留请求 ID，网络错误退避重试，最大间隔 30 秒；恢复在线会触发补发。
- 权限、登录或会话状态导致的 4xx 错误（408/429 除外）保留为失败记录，需手动重试或移除。每次补发重新验证服务端权限，客服发送同时校验账号 ID。移除待发记录不撤回已经被服务端接受的消息。
- 队列按访客会话或客服账号隔离。客服退出登录时清理该账号待发记录。没有跨设备队列同步；清理站点数据或浏览器存储会丢失尚未送达的本地消息。
- Service Worker 仅缓存静态应用文件，不缓存私有 API 数据。首次在线加载完成后，HTTPS/localhost 支持离线刷新；客服离线页面可查看待发记录，恢复后需重新验证登录，历史消息不离线缓存。
- 每条消息拥有持久化递增 `seq`。客户端显式确认送达/已读游标，游标只增不退；读取接口本身不再标为已读。已读表示页面可见且消息区处于底部后确认到该游标，不代表人工理解了内容。
- 客服 `POST /api/conversations/:id/receipts` 与访客 `POST /api/widget/receipts` 接受 `deliveredSeq` / `readSeq`。消息 GET 可传 `after` / `limit`（最多 200），返回 `nextCursor` / `hasMore`；内部备注与其他会话的游标受权限校验。
- 仍使用 SSE 通知与 HTTP 补偿刷新，没有持久化事件日志、WebSocket、跨端撤回协议或端到端加密。

## 数据与部署

- `HOST` 默认 127.0.0.1，`PORT` 默认 4310，`DB_PATH` 可更改数据库位置。
- HTTPS 反向代理使用 `COOKIE_SECURE=1`；SSE 端点需关闭代理缓冲。
- 当前支持单组织内管理员/客服两类角色，无完整自定义权限、限流、监控和租户隔离。
- 停止服务后备份 `data/` 全目录；运行中的 SQLite WAL 数据不能仅复制主数据库文件。
- 网站组件仅允许同源 iframe 嵌入。
- Dockerfile 已提供；当前版本尚未完成容器构建和运行验收。

## 结构

- `server.mjs`：HTTP、认证、消息、资源、模型接口和数据迁移。
- `lib/management.mjs`：邀请、基础角色、会话筛选/批量、话术、标签、操作记录及协作数据迁移。
- `public/inbox.js` / `public/management.js`：客服工作台与后台管理页面。
- `lib/features.mjs`：知识集合索引、工具与工作流接口、运行持久化。
- `lib/knowledge.mjs`：文本分块、BM25 排序、静态 HTML 提取。
- `lib/workflow.mjs`：DAG 校验、分支和节点执行。
- `lib/integrations.mjs`：MCP、OpenAPI、Schema 校验与远程请求。
- `public/`：客服界面、功能编辑器和访客组件。
- `tests/`：接口、协议与执行引擎测试。

工作流草稿与发布版本：编辑草稿使用修订号保护，冲突返回 409 并保留编辑窗口，可导出本地 JSON 草稿。复制粘贴针对当前编辑器中的单个节点，最多保留 100 步画布历史。发布快照不可修改，恢复历史版本只更新草稿，运行时可选择草稿或任意已发布版本。发布快照不冻结外部工具、知识库和模型配置。知识/模型节点默认不重试，最多额外重试 3 次，间隔不超过 5 秒；工具节点不自动重试。

OpenAPI 支持 JSON/YAML 输入、文档内 `$ref`、常用数组/对象查询参数。循环和外部引用、Header/Cookie 参数、非 JSON 请求体尚未支持。外部服务仍须由服务器环境变量显式加入允许列表。

## 网站知识采集与后台任务

知识库 → 网站采集与同步 → 添加来源。填写已允许的 HTTP(S) 入口，设置路径范围、页数和链接深度。默认只手动采集，勾选后可按 15–43200 分钟周期同步。页面列表和任务状态在同一面板查看，任务进度通过“刷新任务”更新。

- 仅跟随同 origin 且处于指定路径内的链接；不会跟随 HTTP 重定向，不发送登录 Cookie，也不执行网页脚本。origin 必须精确加入 `INTEGRATION_ALLOWED_ORIGINS`。
- 每次 1–30 页，链接深度 0–5；单页响应最多 1 MB、正文 200,000 字符；整次响应最多 5 MB、正文最多 1,000,000 字符、120 秒。
- SQLite 保存采集任务与来源快照；同来源仅有一个待执行/执行中任务。单实例一个后台任务执行，最多 100 个活动任务。失败自动重试，总计最多 3 次；重启时未完成任务重新排队并重新采集，第 3 次尝试中断则标为失败，不是逐页断点续传。
- 采集完成后批量更新文档和索引，入口失败保留原有数据；子页失败可导入成功页面，并保留未成功更新的旧页面，任务显示“部分完成”。未变化内容保留分块 ID，不自动删除本次未发现的旧页面。
- 可取消、重新采集、调整来源所在知识库。来源有活动任务时不能修改配置或移除；已有采集页面后入口地址不能更换，需新建来源。
- 采集文档由来源维护，避免单独修改后又被同步覆盖。移除来源保留文档，解除管理关系后可独立编辑和删除。
- 目前不支持 JavaScript 页面渲染、登录态抓取、robots/sitemap 规则、自动清理旧页面或分布式 worker。此持久队列仅覆盖网站采集，PDF/文本导入及工作流仍保留原执行方式。

## 三个接入平台（0.8.0）

后台「接入平台」提供网页端、Flutter / Dart SDK、Telegram 客服话题。

- 网页端：复制脚本嵌入代码；跨站嵌入前配置完整来源 origin。平台可独立停用并设置标题。
- Flutter / Dart：后台下载包，或查看 [SDK README](sdk/fastcat_support/README.md)。公开 appKey 区分接入配置，访客 token 单独鉴权；原生客户端无需 Origin，Flutter Web 需配置来源。
- Telegram：访客仍从网页或客户端咨询，转人工后向指定超级群创建话题；客服在话题内直接回复文字/文件，原会话实时接收。不会提供用户私聊 Bot 联系客服入口。

Telegram 配置：Bot 需为开启话题超级群的管理员，并拥有管理话题权限。填写 Bot Token（服务端 AES-GCM 加密，主密钥沿用 `<DB_PATH>.key`）或 `FC_SECRET_` 环境变量、负数群 ID、客服个人数字 ID 与工作台成员映射、公网 HTTPS origin；保存后检测连接并注册回调。修改 Bot / 群组后须重新注册回调。回调为 `/api/telegram/webhook`，使用独立 Secret Token 验证；只接收指定群、已建立话题和已绑定客服的消息。匿名管理员、Bot、私聊和未绑定身份均不转发。

初次带入最近 0–30 条公开消息（0 表示仅最近一条）；内部备注不会转发。客服继承工作台分配权限，其他坐席的会话需先转交或由管理员处理。会话结束后不接收话题回复；TG 的话题生命周期、编辑和删除不自动同步。

发送结果不确定时暂停自动重发；先核对群消息/话题，再通过「消息与话题」绑定已有话题或重试，避免重复。429 自动延迟重试。失败的客服回调可在记录中重试。真实 Telegram 联调仍需有效配置；本地测试仅模拟 Bot API，不含真实凭据。

## 0.9 对齐取舍

- 接入平台支持多个网页/Flutter 实例，独立配置角色与 AI 自动/人工优先/纯人工模式。默认入口采用人工接待；客服回复、主动接管、转交和结束会话会阻止 AI 覆盖。
- 网页支持主题、Logo HTTPS 地址、四角位置和专属欢迎语，保存后可打开实际嵌入演示。新实例默认停用；归档保留历史，恢复后仍停用。默认入口只可停用。
- 重新生成公开标识后须更新旧嵌入代码和 SDK 配置；访客 token 与历史保留。
- 智能体可多选知识库，并发现、绑定具体 MCP/OpenAPI 操作。模型调用授权操作、取得结果后继续回答；调试、草稿、平台 AI 回复使用同一链路。已有角色协作扩展保留。
- 工具参数校验；单次生成最多 16 次远程调用、1–5 轮模型请求、180 秒，默认 3 轮含最终回答。配置、账号或会话权限变化阻止后续执行；失败或未知结果不自动重试，取消不能撤销已完成的操作。
- 调用元数据位于「模型管理 → 工具执行记录」，不存参数与返回正文。尚无智能体主动调用工作流、业务动作工具、Skills 或向量检索。
- Flutter 新增未读 Launcher、全屏聊天、AI 草稿与连接状态；仍为轮询，无系统推送。
- 工具、模型、智能体商店不开发；本地配置保留。Telegram 仍只供客服群话题回复。

详细结果见 [功能对齐报告](docs/REFERENCE-AUDIT.md)。

默认进入会话收件箱，总览页面及其代码已移除。智能体可展开工作流、工具集成、技能与设备三个二级入口；团队管理合并团队成员和接待团队，并在页面内切换。原有直达链接与后台权限继续生效。

## 0.18 团队工作时间与回车发送

工作空间自动接待模块已移除，包括全局开关、欢迎语、关键词分流、自动坐席分配、默认自动答复设置和记录接口。历史数据库内容保留但不执行。工作时间迁至“团队管理 → 工作时间”，旧时段自动迁移一次。

接入平台独立 AI 策略、智能体调试、人工接管仍提供。默认/旧 inherit 入口采用人工接待，需在接入平台显式选择 AI 才会启用。团队工作时间约束平台 AI，非工作时间提示仍可配置，人工回复不受限制。

网页客服端和用户端使用 Enter 发送、Shift+Enter 换行；中文输入法组合确认不发送。

## 0.19 转人工分配

访客明确请求人工后，按团队范围、可接待状态和容量分配客服；无可用客服则进入等待分配队列，恢复可接待或释放容量后重试。普通未分配会话不自动领取，人工手动取消分配也不会被立即领回。全局自动接待模块仍不提供。

## 0.20 模型服务配置

模型管理统一为“模型配置”和“调用记录”。添加模型服务时，在一个弹窗配置供应商连接、读取并多选模型或手动填写模型标识，可同时设置默认对话/Embedding 模型；最后统一保存。取消或保存失败不会留下半成配置。已有服务下直接追加、配置、测试模型，连接配置中的密钥留空保留。无商店与计费，现有模型及业务绑定保持兼容。
